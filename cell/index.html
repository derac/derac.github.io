What the image tells us

The cached artwork is Cellularity d_0020 by Jonathan McCabe. Its native image is 59,049 × 59,049 pixels. Broad smooth forms contain fine stripes, spots, and sharply different neighboring textures.

A useful correction

McCabe’s description of Cellularity specifies four floating-point values per pixel, neighbor diffusion, and polynomial reactions influenced by the values’ history. This is distinct from his earlier multiscale Turing model. A licensed Cellularity description also mentions an expanding space.

The two experiments

Independent Turing scales: each scale has its own radius, inhibition range, reaction strength, preference, regional response, and color. All six compete on one shared pattern field. Separate history channels preserve their local influence. Smooth averaging uses three box-filter passes to approximate a Gaussian; Square box keeps the earlier kernel.

Regional reactions: two concentrations, two history fields, and evolving regional fields that vary feed and kill rates across the image. Different regions can develop different kinds of cells. This is an experimental construction, not McCabe’s recovered polynomial map.

Color: Independent layers blends six separately colored ramps using the retained layer histories. Multichannel spectrum maps several state dimensions independently into RGB. Original single palette keeps the earlier mapping for comparison. Layer colors can be edited directly; color seeds now generate new ramps instead of only rotating a short list.

Inflation: an optional resampling step expands structures about the center while the simulation adds new detail. It runs on a fixed grid, so this is an approximation to a growing domain.

How to explore

  1. Start with a preset and let it develop for several hundred steps. The speed slider sets a target of 1–2,000 steps per second. You can type an exact rate or choose Slow, Normal, Fast, or Very fast. This changes playback timing, not the reaction rules.
  2. Move a pad to alter two parameters. Use the axis menus to change the pair. Lock X or Y to hold that axis during dragging and arrow-key adjustments. Hold Shift before dragging, or with the arrow keys, for finer control. Select 2× closer or 2× wider to change the range.
  3. Space plays or pauses; [ and ] halve or double speed; . advances one step and pauses. These shortcuts leave text fields and buttons alone. The +1 and +100 buttons also advance a paused simulation.
  4. Pause, then change palette phase, color cycles, or the color seed. Switch to Scalar field to separate geometry from coloring.
  5. Save state before changing the rule. It stores the complete simulation, the settings, and the step count so you can resume the same experiment.

Playback speed is remembered on this device. It is separate from saved simulation states. Pausing or switching tabs clears the playback backlog, so returning does not cause a burst of catch-up steps.

New rules depend on the current field. Use Restart seed for a controlled comparison. Changing model or resolution starts over. Checkpoints now contain eight floats per pixel. Old checkpoints retain the original pattern, but their missing layer histories must be approximated on import. Equal seeds are reproducible on the same backend; floating-point differences between GPUs and the CPU can diverge over time.

What remains unknown

The exact polynomial map, history mechanism, coefficients, color mapping, seed, growth schedule, and iteration count for d_0020. Neither mode claims a pixel-for-pixel reconstruction. Optional relief shading is a display effect added here.
